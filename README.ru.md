# Как работают языковые модели — наглядно

[Read in English](README.md)

Интерактивное объяснение без формул — о главной идее, на которой держатся чат-боты, переводчики и автодополнение в телефоне: **языковая модель — это машина, которая угадывает следующее слово.** Всё остальное — детали этого угадывания.

Страница состоит из девяти коротких разделов. В каждом есть небольшая демонстрация, которую можно потрогать руками: идеи видно в работе, а не нужно принимать на веру.

## Что внутри

| № | Раздел | Идея |
|---|--------|------|
| 01 | Угадай слово | Модель для каждого возможного следующего слова называет вероятность. |
| 02 | Токены | Текст режут на кусочки (токены), и модель работает с их номерами. |
| 03 | Контекст | Смысл слова берётся из соседних слов и хранится как набор чисел. |
| 04 | Внимание | Каждое слово «смотрит» на другие и решает, какие из них важны для его смысла. |
| 05 | Токен за токеном | Ответ собирается по шагам, и на каждом шаге модель перечитывает всё написанное. |
| 06 | Температура | Ручка, которая задаёт, осторожно или смело модель выбирает следующий токен. |
| 07 | Обучение | Вероятности никто не прописывает вручную: их подстраивает обучение. |
| 08 | Устройство | Этапы работы модели и то, как её размер зависит от слоёв и ширины. |
| 09 | И это всё? | Тот же принцип в огромном масштабе и причина, по которой модель иногда звучит убедительно, но ошибается. |

## Для кого

Для тех, кто каждый день пользуется языковыми моделями и хочет понимать, что происходит внутри, без линейной алгебры и подготовки по машинному обучению.

## Как устроены демонстрации

Демонстрации намеренно сделаны на **игрушечной** модели, и страница об этом честно говорит:

- Разделы 01, 05 и 06 считают частоты слов во встроенном небольшом русском корпусе (шаблоны из одного, двух и трёх слов с откатом на более короткие). Это таблица подсчётов, а не нейросеть, но она выдаёт настоящее распределение вероятностей следующего слова — тот же интерфейс, что у большой модели.
- Разделы 02 (токены), 03 (карта слов), 04 (внимание) и 07 (обучение) — иллюстрации. Их числа подобраны для наглядности и не получены из обученной модели.
- Раздел 08 оценивает количество параметров и размер файла по формуле `12 · L · d² + 2 · V · d` при точности fp16. Это приблизительная оценка.

Страница работает полностью офлайн, без сборки и без внешних зависимостей.

## Запуск

Сборки нет, зависимостей тоже. Сайт — это обычные HTML, CSS и JavaScript.

Можно открыть файл напрямую:

```bash
xdg-open index.html   # Linux; на macOS — `open index.html`
```

или поднять любой статический сервер в папке проекта, например:

```bash
python3 -m http.server 8000
```

и открыть <http://localhost:8000>.

### Тесты

Логика ядра (токенизатор, модель на n-граммах, температура, генерация, иллюстрация обучения, оценка размера) покрыта юнит-тестами на встроенном тестовом раннере Node. Нужна Node 18 или новее.

```bash
node --test js/tests/*.test.js
```

## Структура проекта

```
index.html        Разметка и тексты страницы
styles.css        Стили
js/corpus.js      Встроенный текст, на котором учится игрушечная модель
js/model.js       Токенизатор и модель на n-граммах: счёт, предсказания, температура, выбор
js/generation.js  Пошаговая генерация текста
js/learn.js       Иллюстрация обучения
js/params.js      Оценка размера модели
js/embeddings.js  Данные для карты слов
js/demo/*.js      По файлу на каждый интерактивный раздел
js/main.js        Однократно собирает игрушечную модель и запускает все демо
js/tests/         Юнит-тесты
```
